# lvove-game

A cozy date-night memory game for two, with matching cards, hearts to collect, a story prompt on every match, and a little message corner.

## Run it

Open `index.html` in a browser. The game is a static first prototype and needs no build step.

## What's here

- A memory-match game for two players taking turns on one screen.
- Quick, classic, and long game lengths with 4, 6, or 8 pairs.
- Earn a heart and a sweet conversation prompt for every matching pair.
- A local message corner with player labels and a clear-notes control.
- Responsive layout for desktop and phone screens.

This version is single-device. Messages and game progress do not sync to another person's browser yet; shared rooms and live chat need a small online backend.
